# 나 면 — 재는 면

★★ **가 면을 다 쓴 뒤에 연다.** 같은 자리에서 동시에 쓰면 지목할 수 있게
  답안을 맞추게 된다. 순서가 이 시트의 절반이다.

## 물음 — 답안마다 한 번

```
마지막 줄이 왜 통하는지를 대라. 앞 세 줄 중 무엇을 드는가.
★ 최소로 든다. 셋을 다 들면 언제나 설명이 되니 그건 답이 아니다.
★ 빼 보는 것이 아니라 들어 보는 것이다.
```

## 판정

```
L3      셋을 다 들어야 설명이 된다
L2      둘을 들면 된다
L1      하나를 들면 된다
L0-나열  앞 세 줄이 같은 장면인데, 무엇을 들어도 마지막 줄이 왜 통하는지 안 나온다
L0-압축  들 앞줄이 아예 없다시피 하다
```

★ `L0` 을 두 얼굴로 가른다. 한 칸이면 한쪽으로 몰린다.
  그리고 둘이 다르다는 것은 이미 잰 값이다 — 규칙이 나열은 물고 압축은 0/8 이었다.

★★ `L1` 과 `L2` 가 안 갈리면 축 1 은 4단이 아니라 3단이다. **그것도 값이다.**
  갈라지게 쓰려고 답안을 고치지 마라. 쓴 것을 그대로 재라.
