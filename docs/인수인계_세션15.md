```

```
낱낱 나열
  턴은 제대로 돈다        A가 치고 → 상대가 막고 되받고 → A가 피하고

## 4. L 을 지목형으로 확정했다

`docs/경계표본_작성시트.md` 1장이 본문이다.

```
물음   마지막 줄이 왜 통하는지를 대라. 앞 세 줄 중 무엇을 드는가.
       ★ 최소로 든다.
       ★ 빼 보는 것이 아니라 들어 보는 것이다.
```

★★ 두 별표는 **주석이 아니라 정의의 일부다.**
`최소` 를 빼면 `L3` 이 무의미해진다 — 셋을 다 들면 언제나 설명이 된다.
`빼 보는 것` 으로 쓰면 그건 `delete` 이고, 12장에서 죽었다. `지목` 물음이 살아난
이유가 반사실이 아니라는 것 하나였으니, 정의도 지목형이어야 한다.

★ `L0` 은 두 얼굴이다(나열 · 압축). 낱낱 나열의 앞 세 줄은 **딴 얘기가 아니다.**
`앞이 딴 얘기다` 로 정의하면 낱낱 나열이 `L0` 에 안 들어가고 표본이 압축 쪽으로만
쏠린다.
