```

이 프로젝트가 만난 같은 모양이다. **셋째와 넷째가 이 세션에서 생겼다.**

```
적혀 있는 것과 걸리는 것은 다르다              daily_spend_cap_usd 20 을 읽는 코드가 없었다
통과하는 것과 문다는 것은 다르다               검사가 통과해도 병을 넣어야 문다
★ 예측한 것과 잰 것은 다르다                  설계안 v0 의 표가 셋 다 잰 것처럼 적혀 있었다

넷째가 이 세션의 값이다. `has_actor` 가 `0/8` 대 `137/144` 로 갈리는 걸 보면 합격선에
넣고 싶어진다. **넣으면 0장 요건이 넣으라고 한 `짧게 끊은 마지막 줄` 일곱이 죽는다.**
