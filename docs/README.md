인수인계가 아홉 개다. **다 읽지 마라.** 아래에서 `살아 있다` 표시가 붙은 것만
지금 일에 걸린다.

세션 11이 다섯 세션 전(세션 6 §12)에 적힌 조건을 안 읽고 목록을 짰다가
킬스위치를 빠뜨렸다. 문서를 저장소에 넣는 것만으로는 그게 안 막힌다 —
**끝난 것과 안 끝난 것이 갈려 있어야 아홉 개를 다 안 읽어도 된다.**
